## Descrição

Utilizamos no projeto o conceito de herança em Java para que as classes Carro e Moto herdem as propriedades e métodos da classe Veiculo. Dessa forma, evitamos a duplicação de código e podemos reutilizar os atributos e comportamentos comuns aos veículos.
